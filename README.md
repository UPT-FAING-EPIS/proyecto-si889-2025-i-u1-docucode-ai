# 📘 DocuCode-AI

Sistema web inteligente basado en IA para la evaluación, documentación y análisis de código fuente con generación automática de diagramas UML.

## 🔍 Descripción General

**DocuCode-AI** es una plataforma web académica que permite a docentes y estudiantes analizar código fuente, generar comentarios explicativos, crear diagramas UML, detectar duplicados y evaluar la calidad del código, utilizando la API de OpenAI.

## 🎯 Objetivos

- Reducir el tiempo y complejidad en la revisión de código.
- Promover buenas prácticas de programación desde el ámbito académico.
- Implementar herramientas automatizadas con IA para análisis estático.

---

## 🧩 Funcionalidades

- Subida de archivos `.php`, `.py`, `.zip`, `.rar`
- Análisis automático del código con GPT
- Generación de comentarios explicativos
- Evaluación de calidad de código
- Detección de código duplicado
- Generación de diagramas UML:
  - Clases
  - Casos de Uso
  - Secuencia
  - Actividades
  - Componentes
  - Paquetes
- Historial individual por usuario
- Autenticación con Google
